Мод "Self Shot" для TACZ (Forge 1.20.1). Только пистолеты. Кнопка V.

СБОРКА ЧЕРЕЗ GITHUB (ничего ставить не надо):
1) Создай репозиторий на github.com (New repository).
2) Загрузи в него ВСЁ содержимое этого архива (Add file -> Upload files),
   включая скрытую папку .github. Лучше через git, т.к. браузер иногда не грузит скрытые папки.
3) Положи jar TACZ в папку libs/ репозитория и закоммить.
4) Вкладка Actions -> build -> дождись зелёной галочки (3-6 минут).
5) Внутри запуска внизу Artifacts -> selfshot-jar -> скачай, внутри selfshot-1.0.0.jar.
6) Кинь его в mods вместе с TACZ.

Если сборка упала - открой лог шага "gradle build" и пришли мне ошибку.
